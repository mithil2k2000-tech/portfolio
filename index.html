AI engineering

Enterprise Knowledge AI

Python, FastAPI, Qdrant, Claude API, JWT and RBAC, Docker

View code

Problem

Many retrieval systems filter documents after the model has seen them, which leaks content a user should not read.

Approach

Access control runs before retrieval, so the model only receives documents the user is cleared for. Answers carry citations.

Result

98 automated tests and a 12-case evaluation suite scoring retrieval hit rate, citation accuracy and groundedness.

Full-stack and cloud

FinTech Network

TypeScript, React, Fastify, PostgreSQL, Playwright, Terraform, AWS ECS, Helm

View code

Problem

Payment prototypes often fake the hard parts: mutable balances, no real concurrency control, and an AI that could invent a transaction.

Approach

A double-entry ledger is the source of truth, payments are two-step with row-level locking, risk checks are deterministic, and the AI assistant can explain an account but never move money.

Result

17 phases shipped. CI runs unit, integration, Playwright end-to-end and migration-rollback tests.

Cloud security

SentinelCloud

Python, Terraform, OPA/Rego, Kubernetes, Claude API

View code

Problem

Security findings across clouds are hard to trust when a model is the one making the call.

Approach

Policy as code decides. The model only explains findings after the deterministic verdict. Includes threat modelling and drift detection.

Result

295 tests across a 13-job CI pipeline with deployment gates, run on simulated environments at zero cloud cost.

Research and MLOps

Explainable AI reliability

Python, CatBoost, Random Forest, SHAP, LIME

View code

Problem

Model explanations can change when data drifts, so a good explanation today does not prove a trustworthy one next month.

Approach

My MSc dissertation builds a cloud-native MLOps workflow with offline explainability and batch-level monitoring, and proposes an Explanation Stability Score, on a public recruitment dataset.

Result

25-run cross-validation with 95% confidence intervals. A research prototype, not a deployed hiring tool.
